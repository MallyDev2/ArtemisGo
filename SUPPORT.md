# Support

For help with ArtemisGo, start from the tunnel dashboard and confirm the local service is running before starting the client.

## Before Asking for Help

- Confirm the local server is running.
- Confirm the tunnel is active in the dashboard.
- Run `ArtemisGo` from a fresh terminal.
- Keep setup keys and logs with credentials private.

## Security Reports

Report security issues privately to the project owner. Do not post setup keys, credentials, or private dashboard screenshots in public issues.
