# Security Policy

## Reporting

Please report security issues privately through the project owner instead of opening a public issue.

Include the affected platform, install command used, expected behavior, and what happened.

## Sensitive Data

Do not share tunnel setup commands, setup keys, connection credentials, screenshots that show private dashboard data, or logs that include local paths.

## Supported Scope

This repository contains the public ArtemisGo installer entrypoints. Tunnel credentials and runtime configuration are issued by the ArtemisGo dashboard.
